# Yak Ops v1.0.0

**Released:** 2026-09-29

## Overview

Yak Ops 第一个稳定发布版本，提供可部署的数据源管理、单表离线同步和 MySQL CDC 实时同步主链路。

## Highlights

- **单表离线同步：** 从 MySQL 读取，写入 MySQL、PostgreSQL 或 Oracle，支持 APPEND、OVERWRITE、UPSERT。
- **实时同步：** MySQL CDC 通过 Debezium 初始化快照与持续 Binlog 消费，写入 MySQL、PostgreSQL 或 Oracle。
- **任务与运行记录：** 分离 Task Definition 和 Instance，提供人工运行、停止、实例历史和读写行数。

## New Features

- 平台：用户登录和管理、Workspace 隔离与成员管理、用户级 Workspace 选择保持。
- 数据源：MySQL 5/8、PostgreSQL、Oracle 的连接管理、测试与 Catalog 元信息；MySQL 5/8 驱动隔离。
- 离线：MySQL JDBC Source Split、并行读取和原生 UPSERT（MySQL `ON DUPLICATE KEY UPDATE`、PostgreSQL `ON CONFLICT DO UPDATE`、Oracle `MERGE INTO`）。
- 实时：MySQL CDC Snapshot、INSERT/UPDATE/DELETE、Checkpoint、持久化 Offset/Schema History；停止后按照相同 Task 与 definitionVersion 的已完成状态继续。
- 运维：运行状态、事件与读写指标。正式版本的任务定义与执行操作各有明确入口。

## Improvements

- 初始稳定版本提供版本化 Distribution、Docker 镜像和可追溯的发布验证流程。
- 发布前完成五个手工 E2E 场景：APPEND、OVERWRITE、UPSERT、Snapshot + 变更流、Offset 续传（详见历史记录）。

None（首个稳定版本，不承诺从早期开发版或 v0.1.0 自动升级）。

## Compatibility

- 构建/运行：Java 21。
- 数据源类型：MySQL 5/8、PostgreSQL、Oracle；离线 Source 仅承诺 MySQL，实时 Source 仅承诺 MySQL CDC。
- 离线、CDC Target：MySQL、PostgreSQL、Oracle。具体兼容性以本版已验证的数据源与同步场景为准。
- 实时交付语义：**at-least-once**，不保证 exactly-once。

## Upgrade Guide

首次部署需准备 Yak Ops 元数据库。生产环境必须设置独立的 `YAK_OPS_DATASOURCE_MASTER_KEY`，替换示例密码，并持久化 `${yak.ops.home}/data` 以保留实时 CDC Offset 与 Schema History。支持内置 MySQL 或外部元数据库的 Compose 部署。此版本没有承诺从 v0.1.0 的自动迁移。

## Known Limitations

- 不支持多表任务、自动建表、DDL 传播或 Schema Evolution、Transform。
- 不支持定时调度、自动重试、分布式 Worker/HA 或 exactly-once 事务协调。
- 目标表需要预先存在；实时 Source 仅 MySQL CDC。
- 旧活动实例在进程重启后可能标记为 `LOST`；新的实时实例通过持久化 CDC 状态恢复，而不是复活旧实例。
