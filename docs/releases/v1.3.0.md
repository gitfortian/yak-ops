# Yak Ops v1.3.0

## 主要变化

- 数据同步使用统一的 Task Definition / Instance 模型，集中管理任务、执行状态、日志和调度。
- YakFlow 提供 JDBC 数据同步及 MySQL CDC 能力，并持续完善执行、恢复与真实数据库测试。
- MySQL 数据源连接参数统一为 `properties.connectionTimeZone`，MySQL CDC 将其传递到 Debezium JDBC。
- Flyway 合并为一份全新安装基线 `V1__baseline.sql`，直接创建最终的 25 张表（14 张业务表、11 张 Quartz 表）。

## 安装与兼容性

**v1.3.0 只支持空 MySQL 数据库的全新初始化。**

- v1.0.0–v1.2.0 及开发阶段的旧 Flyway 数据库 **不支持原地升级**；不要直接把现有数据库或 Docker 数据卷用于 v1.3.0。
- 上线前需要备份已有数据库及数据卷，并明确选择新建空库。保留旧数据时必须单独设计、评审和验证迁移方案。
- 新基线不执行历史业务数据的 `UPDATE`、`DELETE`、`INSERT`，不删除现有表，不自动转换 `serverTimezone` 数据。
- MySQL 数据源新配置使用 `properties.connectionTimeZone`。旧数据库中的连接参数不会被自动修改。
- 请勿手动改写 `flyway_schema_history` 或通过 `flyway repair` 掩盖版本冲突。

## 发布验证

正式发布以 `Release Gate` 的完整 Backend Tests、独立 Docker Compose 空库启动、Flyway V1 验证、Playwright UI 测试及人工复核结果为准。

通过 `Release Gate` 后，以 **同一提交 SHA** 运行 `Release Publish`，生成 GitHub Release 和固定版本的两个镜像：

- `weifuwan/yak-ops:1.3.0`
- `weifuwan/yak-ops-api:1.3.0`

本文件为版本准备说明；PR 合并并不代表发布完成。
