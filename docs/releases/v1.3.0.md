# Yak Ops v1.3.0

**Released:** 2026-10-22

## Overview

本次版本重点是 Task 模型与 YakFlow Core / Runtime / Connector 重构、JDBC 和 MySQL CDC 可靠性建设，以及数据库初始化基线整理。**本版本不是对 v1.2.0 的无损升级。**

## Highlights

- **统一任务模型：** Task Definition 与 Task Instance 分别描述任务和执行，收敛执行状态、日志、调度等管理入口。
- **YakFlow 模块重构：** 将 Core、Runtime、JDBC Connector 和 MySQL CDC 职责重新划分，完善 Checkpoint、取消与恢复相关的基础实现及测试。
- **重新冻结安装基线：** Flyway 收敛为一份新的 `V1__baseline.sql`；**仅支持空 MySQL 元数据库新装**。

## New Features

- 数据同步执行基础：YakFlow JDBC Source/Sink、MySQL CDC（包含快照与 Binlog）相关执行链路与集成测试持续完善。
- Task 平台：统一 Definition / Instance 的数据结构和操作职责，执行、日志及调度作为统一任务模型的组成部分。
- MySQL 时区配置：使用 `properties.connectionTimeZone`，并将配置传递到 MySQL CDC 使用的 Debezium JDBC。
- 数据库新装：新的 Flyway V1 一次建立 25 张表（14 张业务表与 11 张 Quartz 表）。

## Improvements

- 同步基础执行与 JDBC/CDC 测试更聚焦于 Core、Runtime 和 Connector 的职责边界。
- 发布链继续验证版本一致性、分发包、Docker/Compose 启动与数据库初始化；实际运行了哪些测试，应查看对应 Release Gate 的证据，不把未运行的用例写成 PASS。

## Bug Fixes

- 修复与增强主要集中在 JDBC/CDC、Checkpoint、任务执行生命周期和数据库连接配置；具体提交及范围见 [本版 GitHub Release](https://github.com/weifuwan/yak-ops/releases/tag/v1.3.0)。
- 这里不把所有内部重构 PR 逐条当作用户可见缺陷修复。

## Breaking Changes

- **无法从 v1.0.0、v1.1.0、v1.2.0 的已使用元数据库直接升级。** 不能将旧数据卷或已有 Flyway 历史直接用于 v1.3.0。
- 本版重新设计 Task/YakFlow 内部契约，不能假定旧版同步配置、旧数据表、状态文件和产品功能拥有向后兼容的迁移路径。
- 这是一项明确的不兼容变化；虽沿用 `1.3.0` 版本号，也不能解释为符合向后兼容的次版本升级。

## Compatibility

- 分发包运行要求 Java 21；Yak Ops 元数据库使用 MySQL。
- YakFlow JDBC 与 MySQL CDC 适配的行为应以 **v1.3.0 Tag 的可运行代码和实测场景** 为准；旧版 Auto Create、Mapping、SMART Retry 等界面/配置能力不能因为 v1.2.0 曾存在就视为本版继续支持。
- 该版本不提供旧数据库自动迁移或 CDC 旧状态自动转换的承诺。

## Upgrade Guide

**仅全新安装：**

1. 如有旧部署，先完整备份元数据库、Docker 数据卷和持久化的 CDC/任务状态；不要在生产旧库上试跑新 V1。
2. 创建**空 MySQL 元数据库**，使用 v1.3.0 的 Compose/Distribution 配置启动，由新 `V1__baseline.sql` 初始化。
3. 明确配置生产环境数据库凭据和 `YAK_OPS_DATASOURCE_MASTER_KEY`，不要复用示例默认密码。
4. 如需保留旧业务数据，须另行设计、评审并实测迁移方案，本版没有自动升级路径。

新基线不负责转换旧 `serverTimezone` 参数、更新旧业务数据或迁移旧 CDC Offset。**不要直接修改 `flyway_schema_history` 或用 `flyway repair` 绕过不兼容检查。** 回退旧版本需事先验证备份与旧环境，不可假设新版数据库能被旧版直接使用。

## Known Limitations

- v1.0.0～v1.2.0 的数据库及数据卷不支持原地升级。
- 重构后的功能覆盖与旧版不保证一致，特别是旧字段映射、自动建表、运行/重试配置，必须按 v1.3.0 Tag 单独确认。
- 未验证的数据库组合、分布式能力、exactly-once 和状态迁移不能作为正式承诺。
- 发布流程的测试证据以 [Release v1.3.0](https://github.com/weifuwan/yak-ops/releases/tag/v1.3.0) 的正式 Gate 与附件为准。
