## 7. Known Limitations

以下属于已接受的 v1.1 边界，不是隐藏承诺：

- Runtime 仍为 single-node。
- 无 distributed Worker / HA / leader election / fencing。
- 无 exactly-once transaction coordination。
- Offline concurrency 只支持 `SKIP_IF_RUNNING`。
- Quartz 使用 RAMJobStore；enabled Schedule 从 Yak Ops DB 在启动时恢复。
- Retry Policy 没有独立配置 UI。
- Retry backoff 为 process-local；`RETRY_WAITING` 期间重启不会恢复同一 Attempt chain。
- Realtime Auto Recovery 是 startup reconciliation，不是 continuous watchdog。
- Realtime continuation 保持 at-least-once。
- Runtime Trace 当前为本地 file-backed storage；无 S3 / MinIO、retention policy、全文检索或 REALTIME Runtime Trace。
- Auto Create Table、Logical Modeling、Multi-table、Transform 与更多 CDC Source 均不属于本版本。
