```text
YakFlow Runtime Trace Contract
JDBC Source Split / Sink Batch Diagnostic Events
File-backed Offline Execution Trace Store
Offline Execution Diagnostics UI
```

Responsibility boundary:

- Runtime Trace is best-effort diagnostic data and cannot change Data Sync execution success/failure.
- Trace does not persist YakRow business values or Sink bind parameters.
- OFFLINE Attempt diagnostics persist under `${yak.ops.home}/data/data-sync/execution-traces`.
- OFFLINE Task Detail consumes Summary + Source Split + Sink Batch diagnostic APIs.
- Execution lifecycle product events remain auxiliary audit context.
- REALTIME Runtime Trace is not part of v1.1.0.
