## 7. Known Limitations

以下边界已接受，不阻断 v1.2.0：

- Runtime 仍为 single-node。
- 无 Distributed Worker / HA / leader election / fencing。
- 无 exactly-once transaction coordination。
- Realtime continuation 保持 at-least-once。
- Realtime Auto Recovery 仍是 startup reconciliation，不是 continuous watchdog。
- Logical Table Persistence 尚未实现。
- 无 Catalog Refresh / Schema Diff。
- 无 DDL Sync / Automatic Schema Evolution。
- 无 Multi-table Task。
- 无 Transform / Expression / Custom SQL Mapping。
- Source CDC 仍只支持 MySQL。
- Runtime / Retry tuning 不提供普通用户配置 UI。
- Runtime Trace 仍为本地 file-backed；无 retention / object storage / full-text search / REALTIME Trace。
- 通用 YakFlow Checkpoint 不提供跨进程恢复。
