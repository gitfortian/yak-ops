## 逐票明细

**03 · 「重新采集」200 零反馈**
实测点「重新采集」返回 200，页面**没有任何**进行中/成功提示，成功与否要看运气刷新。改法：与任务页「立即运行」同一套反馈（toast + 该资产行状态进入「采集中」并可轮询到终态）。
验收：点击后 3 秒内有可见状态变化；失败有可见原因（不吞 4xx/5xx）。

**04 · 整行不可点 / 操作只有图标**
- [shared/asset-table.tsx:61-67](../../../yak-ops-ui/apps/web/app/data-map/shared/asset-table.tsx) 只有表名 `<Link>` 可点，整行不可点，命中率低；
- `tasks/page.tsx:347` 的任务行操作是图标按钮，`label` 仅在 `aria-label` 里（`:86`），「立即运行 / 删除」靠悬停猜。
改法：行级可点（键盘可达 + Enter 打开），高频操作给可见文字。
验收：鼠标点行任意空白处进详情；键盘 Tab→Enter 同样可达；操作列文字可读。

**05 · 徽章语义混淆**
任务列表同时出现状态徽章「运行中」（实为「已上线」）与「最近运行 · 尚未运行」，两种状态被塞进一个字段。拆成两列：**上线状态**（草稿/已上线/已下线）与**最近实例**（未运行/成功/失败 + 时间）。
验收：新建未运行的任务显示「已上线 · 尚未运行」；运行中实例显示耗时与结果；两列各自 tooltip 说明。

**06 · placeholder 被当选项**
采集任务页的选择器把「选择数据源」「选择数据库」作为**第一项可选项**列出（实测可选中）。占位符应只作占位，不进候选。
验收：候选列表内无占位文本；清空后回到 placeholder 态且不可提交。

**07 · 未知路由静默改道（需确认归属）**
直接访问 `/data-map` 落到 `/data-source` 而不是 404。`apps/web/app/router/` 与 `App.tsx` 内未见 `path: "*"` 兜底。**路由与 App 级文件是否属可改范围需用户确认**（本模块授权只覆盖 `data-map/**`）；确认后加 NotFound 路由 + 明确的重定向理由。
验收：未知路径显示 404 页；已删除的旧路径若有重定向，须在代码注释写明来源。
