## 三、授权边界（硬约束）

- **可改前端**：仅 `yak-ops-ui/apps/web/app/data-modeling/**` 与 `yak-ops-ui/apps/web/app/data-map/**`（票 26 的 `autoHighlight` 落在 data-map 采集任务编辑页）。`packages/yak-ui/**`、`apps/web/themes/**`、`scripts/**` 属 upstream，本批一律**只上报不改**。
- **可改后端**：`yak-ops-dao`（mapper）、`yak-ops-business/yak-ops-business-modeling`。改后端契约（DTO/REST/持久化）前先确认是否升级为 FYOIP。
- **越界项**：08（数据源库可见范围）、以及 `docs/data-sync/issues/tickets.md` 全批——需用户授权后再动。
- 全程遵守 `AGENTS.md`：迁移不可改已应用文件、Workspace 隔离不破、注释/JavaDoc 用英文、用户文案保持本地化。
