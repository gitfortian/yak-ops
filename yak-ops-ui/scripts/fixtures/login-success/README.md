# Login Success Expression Reference

两张 SVG 是浏览器可见图形的矢量提取，仅用于角色群与局部五官评审，不在产品代码中导入。

`before.svg` 对照旧成功表情，在弹跳结束、下沉开始前暂停各角色的结果动画；`after.svg` 对照新的成功定格。静态图不表达动画时间差，也不构成真实认证、状态切换或浏览器回归已经通过的证明。

造型与交互约束见 [App Rules](../../../apps/web/APP_RULES.md#success-authored-pose)，验证命令与证据边界见 [Tooling](../../../docs/tooling.md#tests)。调整成功造型时应重新核对浏览器定格与该参考，不手工修改参考图来掩盖实现差异。
