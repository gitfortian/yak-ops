# Table 数据区边框与内容高度

状态：生效。

范围：`packages/yak-ui/src/table/**`，以及复用 Table 的数据源、离线同步、实时同步、运维和管理页面。

## 视觉与布局约定

- 表头使用已有灰色背景，不绘制表头外框或列间竖线。
- `bordered` 默认为 `false`：只保留数据行底部分隔线。
- `bordered={true}`：仅数据区绘制完整网格。每个单元格画右边和底边，首列补左边，首行补顶部；最后一列的右边和最后一行的底边不能省略。
- 使用同一数据区边框 token 和折叠边框，不叠加滚动容器边框，避免双线和深浅不一致。
- 数据区高度由实际内容决定。一条数据时，网格就在这一条数据后结束；没有隐式占满剩余高度的行为。
- 页面白底可以继续铺满。已有调用方的 `min-h-full` 只影响 Table 外壳，不再拉伸数据区或把分页推到页面底部，无需逐页覆盖样式。
- `scroll.y` 仍表示滚动视口的最大高度，不是固定高度；数据不足时不补空白行。横向滚动和吸顶表头继续由同一个原生表格承载，不拆成两个表格。
- 分页与 `footer` 仍复用同一底栏，但与数据网格分离，间距为 12px，不额外绘制顶部横线，也不使用自动外边距推到底部。

## 加载与空态

空数据和首次加载保留既有 `min-h-48` 占位，不因内容高度布局而塌陷。空态单元格使用与数据区相同的边框约定；首次加载不同时显示“暂无数据”。

加载时保留当前行。遮罩位于滚动视口外的定位层，宽高只覆盖可见表体，不进入表头、滚动条、分页或页面剩余白底。根据实际表头单元格的位置计算遮罩顶部，不依赖 small / medium / large 的固定高度猜测；加载期间监听视口和表头尺寸及滚动变化，结束后清理观察器和监听器。

吸顶状态下测量实际 `th`，不能用已经滚出视口的 `thead` 位置替代。非吸顶表头滚出视口后，遮罩可以从视口顶部开始。分页在加载期间保持可见且禁用。

## 验收步骤

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 单行 | 在离线同步中仅保留一条任务，调整浏览器高度 | 表头无外框；数据区四边闭合；下面白底无边线；分页跟随数据 |
| 多行 | 查看多条任务及多行单元格内容 | 列间和行间仅一根细线；首行顶部、首列左侧、末列右侧和末行底部完整 |
| 无边框模式 | 使用不传 `bordered` 的 Table | 只有行底部分隔线，没有数据区左右框和竖线 |
| 空数据 | 查询一个无匹配结果的关键字 | 保留稳定空态高度；空态边框闭合；没有撑到页面底部的大框 |
| 首次加载 | 开启网络限速后刷新列表 | 表头始终可见；只有加载提示，没有同时出现的空态文字；加载结束后网格随真实行数收口 |
| 刷新已有数据 | 保留一条或多条记录时触发刷新 | 原数据不被卸载；遮罩只覆盖可见表体；分页保持可见且不可操作 |
| 横向滚动 | 缩窄窗口，滚到最右侧，再触发加载 | 表头和数据列保持对齐；末列右边框存在；遮罩覆盖可见宽度，不随内容横移；底栏不跟随横向滚动 |
| 纵向滚动 | 设置 `scroll.y`，分别启用和关闭 `sticky`，滚动后触发加载 | 最大高度生效但少量数据不撑高；吸顶表头不被遮挡；非吸顶表头离开后遮罩从可见表体顶部开始 |
| 动态表头 | 加载时切换表格尺寸、调整窗口或使用换行表头 | 遮罩起点始终跟随实际表头底部，不残留旧高度 |
| 选择和底栏 | 在数据源页选择记录、使用批量操作及分页 | 选择列也有完整数据区边界；批量操作与分页仍在同一行，行为不变 |
