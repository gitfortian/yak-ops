# Select 定向展开动画

状态：生效。

范围：`packages/yak-ui/src/select/Select.tsx`。适用于所有复用 Yak UI Select 的页面，不改变 Combobox、Menu、Popover 或官网代码。

## 视觉约定

面板从靠近输入框的边缘逐步露出，关闭时沿相反过程收回。不对文字、搜索框和底栏做缩放，也不改变面板参与定位的真实宽高。

采用 `clip-path + opacity`，替换原来的轻微纵向缩放。`Portal → Positioner → Popup` 结构和 `alignItemWithTrigger={false}` 保持不变。不通过高度动画模拟展开，不增加动画库、计时器或第二套开关状态。

方向读取 Base UI 完成碰撞处理后的 Popup `data-side`，不能只看调用方传入的 `side`：

- `bottom`：从上边缘向下展开。
- `top`：从下边缘向上展开。
- `left`：从右边缘向左展开。
- `right`：从左边缘向右展开。

开启时裁切区域过渡至 `inset(-64px)`。负向扩展只保留现有阴影，不增加定位尺寸或真实内边距；不能改成 `inset(0)` 把阴影裁掉。修改阴影 token 时需要同时复查这段视觉余量。

## 时序约定

打开：展开 360ms，透明度 160ms，曲线为 `cubic-bezier(0.16,1,0.3,1)`。

关闭：收回 220ms，透明度 180ms，曲线为 `cubic-bezier(0.2,0,0,1)`。

箭头：打开旋转 360ms，关闭旋转 220ms；过渡属性明确为 CSS `rotate`。选项背景过渡为 150ms，不延迟选中状态或键盘导航，不将其他选项全部淡化。

采用 Base UI 的 `data-starting-style` 和 `data-ending-style`。过渡作用于 Popup 本身，由 Base UI 处理结束后的隐藏与生命周期；不要在退出开始时自行卸载面板，也不要用固定延时猜测动画结束。快速反向操作从当前过渡位置继续。

结束状态禁用 Popup 指针事件。启用系统减少动态效果设置时，面板、箭头和选项均禁用过渡，不保留透明或裁切残影。

## 保持不变的行为

公开参数、值和标签回显、受控与非受控状态、点击打开、键盘导航、焦点恢复及 Escape 关闭继续由现有 Select 和 Base UI 负责。

搜索、刷新、空态和底栏仍由原来的插槽承载；不拆分面板，不复制业务状态。列表保留现有滚动上限。数据刷新改变内容高度时，定位层按完整内容重新计算，不被动画中的裁切比例误导。

## 人工验收

以下是人工验收流程，不能据此声称真实产品页面已经验收。实际执行结果和环境限制在 PR 中单独记录。

### 普通打开与关闭

在数据源或同步任务页面打开短列表，再选择一项或按 Escape 关闭。面板应从输入框边缘逐步展开，文字保持正常比例；收回不中断，关闭后回显和焦点正常。

### 方向与碰撞

在视口底部打开下拉框，确认自动翻到上方并从下边缘向上展开。分别检查上下左右方向；开发者工具中应以实际 `data-side` 为准。动画过程中面板布局尺寸不应由零增大或因缩放而变化。

### 连续反向操作

在打开尚未完成时关闭，再立即打开，重复多次。面板应从当前进度反向过渡，不突然恢复完整尺寸，不残留透明点击区域；最终箭头和面板开关一致。

### 搜索、刷新与空态

在带搜索和底栏的 Select 中输入关键字、清空条件并刷新数据。检查有结果、无结果、加载后恢复和列表高度变化；搜索与底栏不能被压扁，最终没有裁切残留。分别在打开过程中和完全打开后操作。

### 长列表与尺寸

检查 small、medium、large，以及较窄的窗口。长列表仍可滚动，搜索区域和底栏的既有行为不变；选中可见项无需等整段动画完成。检查展开后的圆角、边框和阴影，不能因裁切出现硬切边。

### 键盘与关闭路径

验证方向键、Enter、Escape、Tab、点击外部及选中关闭。搜索输入不应把按键泄漏给列表，关闭后不能留下焦点陷阱；禁用状态继续不可打开。这些需要真实 Base UI 组件验证，纯样式夹具不能替代。

### 减少动态效果

在系统设置或浏览器模拟中启用 `prefers-reduced-motion: reduce`，重新打开和关闭下拉框。面板、箭头和选项不执行过渡，最终状态与普通模式一致。

## 验证边界

沿用现有 `format:check`、`lint`、`typecheck`、`architecture:check` 和 `build`，不新增测试框架或 CI 流程。

独立浏览器样式检查只能验证生成的 CSS、裁切方向、时长、几何稳定性和阴影；它不能证明 Base UI 生命周期、碰撞定位、焦点和真实后端联调已经通过。发布前应在实际页面执行上述操作，并在目标浏览器中观察动画效果。
